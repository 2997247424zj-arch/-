## 🔍 问题排查

### 如果仍然有CORS错误

**检查1：确认后端响应头**

在浏览器开发者工具的 Network 标签中：
1. 找到失败的请求
2. 查看 Response Headers
3. 应该包含：
   ```
   Access-Control-Allow-Origin: http://localhost:5173
   Access-Control-Allow-Credentials: true
   ```

**检查2：确认前端请求头**

在 Network 标签中：
1. 找到请求
2. 查看 Request Headers
3. 应该包含：
   ```
   Origin: http://localhost:5173
   ```

**检查3：查看IDEA控制台**

查看是否有异常信息，特别是关于CORS的错误。

### 如果仍然有401错误

**原因：** 访问需要登录的接口但未登录

**解决：**
1. 先登录
2. 确认浏览器Cookie中有 JSESSIONID
3. 确认请求配置了 `credentials: 'include'`

### 如果商品列表为空

**检查：**
```sql
SELECT COUNT(*) FROM product;
```

**如果为0：**
```sql
TRUNCATE TABLE product;
```

然后重启后端，商品会自动初始化。
