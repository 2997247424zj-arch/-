## 问题排查

### 如果登录响应没有 Set-Cookie

**可能原因:**
- [ ] 后端没有重启
- [ ] application.yml 配置没有生效
- [ ] CORS 配置有问题

**解决方法:**
1. 确认 IDEA 控制台看到 "Started ECommerceBackApplication"
2. 检查 application.yml 中的 Session 配置
3. 查看 IDEA 控制台是否有错误信息

### 如果用户信息请求没有 Cookie

**可能原因:**
- [ ] 浏览器没有保存 Cookie
- [ ] Cookie 的 SameSite 或 Path 属性不正确
- [ ] 前端 withCredentials 没有设置

**解决方法:**
1. 在浏览器 Application 标签查看 Cookies
2. 确认 JSESSIONID Cookie 存在
3. 检查 Cookie 的属性 (Path=/, SameSite=Lax)

### 如果用户信息返回 401

**可能原因:**
- [ ] Session ID 不一致（每次请求创建新 Session）
- [ ] Session 立即过期
- [ ] 拦截器没有正确获取 Session

**解决方法:**
1. 对比 IDEA 控制台中两次请求的 Session ID
2. 如果 Session ID 不同，说明 Cookie 没有被正确传递
3. 如果 Session ID 相同但 userId 为 null，说明 Session 数据丢失

### 如果 IDEA 控制台没有日志

**可能原因:**
- [ ] 代码没有重新编译
- [ ] 使用了旧的 class 文件

**解决方法:**
1. 在 IDEA 中点击 Build → Rebuild Project
2. 重启应用
