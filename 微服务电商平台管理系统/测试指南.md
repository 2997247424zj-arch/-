## 常见问题

### Q1: 页面显示空白
**A**: 检查浏览器控制台是否有错误，确保前后端服务都在运行

### Q2: API 请求失败
**A**: 
1. 检查后端服务是否启动（http://localhost:8080）
2. 检查浏览器控制台的网络请求
3. 确认 CORS 配置是否生效

### Q3: 数据库连接失败
**A**: 
1. 确保 MySQL 服务正在运行
2. 检查 `application.yml` 中的数据库配置
3. 确认数据库 `e-commerce-platform` 已创建

### Q4: 商品列表为空
**A**: 
1. 检查数据库中是否有数据
2. 运行 `src/main/resources/sql/data.sql` 初始化数据

## 下一步

### 启用 JWT 认证
当测试完成后，可以启用 JWT 认证：

1. 在 `WebConfig.java` 中取消注释拦截器代码：
```java
@Override
public void addInterceptors(InterceptorRegistry registry) {
    registry.addInterceptor(new AuthInterceptor())
            .addPathPatterns("/api/**")
            .excludePathPatterns("/api/user/login", "/api/user/register", "/api/product/**");
}
```

2. 在前端 `request.ts` 中启用 Token 携带：
```typescript
request.interceptors.request.use(
  (config) => {
    const token = localStorage.getItem('token')
    if (token && config.headers) {
      config.headers['Authorization'] = `Bearer ${token}`
    }
    return config
  },
  (error) => {
    return Promise.reject(error)
  },
)
```
