## 📊 测试完成后

当你测试完所有功能，准备连接真实后端时：

1. 修改 `src/api/useMock.ts`：
   ```typescript
   export const USE_MOCK = false
   ```

2. 恢复路由守卫（在 `src/router/index.ts` 中取消注释）

3. 恢复认证要求（在路由配置中取消注释 `meta: { requiresAuth: true }`）

4. 启动后端服务
