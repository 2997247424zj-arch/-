## 🎯 功能特点

### 简化登录测试页面特点：
- ✅ **一键选择用户**：点击按钮自动填入用户信息
- ✅ **实时状态显示**：Mock 模式状态、Token 状态
- ✅ **详细错误信息**：登录失败时显示具体原因
- ✅ **API 测试功能**：登录成功后可测试其他 API
- ✅ **快速清理**：一键清除所有测试数据

### 测试流程：
1. **选择用户** → 自动填入用户名密码
2. **点击登录** → 发送请求到后端
3. **查看结果** → 成功则保存 Token，失败则显示错误
4. **测试 API** → 使用 Token 测试其他接口
