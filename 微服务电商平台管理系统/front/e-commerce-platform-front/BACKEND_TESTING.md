## 🧪 测试步骤

### 第一步：检查后端服务

1. 确保后端服务已启动
   ```bash
   cd e-commerce-back
   mvn spring-boot:run
   ```

2. 访问测试页面：http://localhost:5173/debug/connection

3. 点击"检查后端服务"按钮

4. 查看结果：
   - ✅ 绿色 = 后端服务正常
   - ❌ 红色 = 后端服务未启动或无法连接

### 第二步：测试商品列表接口

1. 点击"测试商品列表"按钮

2. 查看结果：
   - ✅ 成功 = 接口正常，显示商品数量
   - ❌ 失败 = 显示错误信息

3. 检查返回的数据格式

### 第三步：测试登录接口

1. 输入用户名和密码（默认：zhangsan / password123）

2. 点击"测试登录"按钮

3. 查看结果：
   - ✅ 成功 = 登录接口正常

4. 检查返回的数据

### 第四步：测试注册接口

2. 自动使用测试数据进行注册

## 🔍 常见问题排查

### 问题1：后端健康检查失败

**可能原因：**
- 后端服务未启动
- 端口号错误（应该是 8080）
- 防火墙阻止连接

**解决方案：**
1. 检查后端服务是否运行
2. 确认端口号是 8080
3. 检查防火墙设置

### 问题2：商品列表接口失败

**可能原因：**
- 数据库未连接
- 数据表为空
- 接口路径错误

**解决方案：**
1. 检查数据库连接
2. 确认数据表中有数据
3. 查看后端日志

### 问题3：登录接口失败

**可能原因：**
- 用户名或密码错误
- 用户不存在
- 密码加密方式不匹配

**解决方案：**
1. 确认用户在数据库中存在
2. 检查密码是否正确
3. 查看后端日志中的错误信息

### 问题4：CORS 跨域错误

**可能原因：**
- 后端未配置 CORS
- 前端代理配置错误

**解决方案：**
1. 后端添加 `@CrossOrigin` 注解
2. 检查 vite.config.ts 中的代理配置
