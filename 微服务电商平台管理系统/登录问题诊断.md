## 🐛 常见问题

### 问题1：点击登录无反应，控制台无错误

**原因：** 前端代码被缓存

**解决：**
1. 清除Vite缓存：`rm -rf node_modules/.vite`
2. 清除浏览器缓存：`Ctrl+Shift+Delete`
3. 使用无痕模式：`Ctrl+Shift+N`
4. 重新启动前端

### 问题2：显示"用户名或密码错误"

**原因：** 数据库中没有用户或密码不匹配

**解决：**
```sql
-- 查看用户
SELECT username, password FROM user WHERE username = 'admin';

-- 密码应该是明文 '123456'
-- 如果不是，重新插入
DELETE FROM user WHERE username = 'admin';
INSERT INTO user (username, password, email, phone, status) 
VALUES ('admin', '123456', 'admin@example.com', '13800138000', 1);
```

### 问题3：显示CORS错误

**原因：** 后端CORS配置问题或后端未启动

**解决：**
1. 确认后端在8080端口运行
2. 访问 http://localhost:8080/api/product/list 测试
3. 检查IDEA控制台是否有错误

### 问题4：登录成功但没有跳转

**原因：** 路由配置问题

**解决：**
1. 检查浏览器控制台是否有路由错误
2. 手动访问 http://localhost:5173/ 查看是否正常
