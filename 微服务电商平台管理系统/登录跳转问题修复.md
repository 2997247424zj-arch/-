# 登录跳转问题修复

## 🐛 问题描述

用户已经登录，但在浏览商品或进行其他操作时，会被重定向到登录页面。

## 🔍 问题原因

1. **路由守卫过于激进**
   - 对所有非登录页面都尝试获取用户信息
   - 如果获取失败（比如 Session 过期），会导致不必要的跳转

2. **localStorage 状态不同步**
   - 初始化时从 localStorage 恢复用户信息
   - 但 Session 可能已过期，导致状态不一致

3. **错误处理不当**
   - fetchUserInfo 失败时没有正确处理
   - 导致用户被错误地判断为未登录

## ✅ 修复方案

### 1. 优化路由守卫逻辑

**修改前：**
```typescript
// 对所有非登录页面都尝试获取用户信息
if (!userStore.userInfo && !to.path.includes('/login')) {
  try {
    await userStore.fetchUserInfo()
  } catch (error) {
    // 获取失败，说明未登录
  }
}
```

**修改后：**
```typescript
// 只对需要认证的页面才获取用户信息
if (!userStore.userInfo && to.meta.requiresAuth) {
  try {
    await userStore.fetchUserInfo()
  } catch (error) {
    // 获取失败，跳转到登录页
    next({ name: 'Login', query: { redirect: to.fullPath } })
    return
  }
}
```

**改进点：**
- ✅ 只在需要认证的页面才验证登录状态
- ✅ 公开页面（如商品列表）不需要验证
- ✅ 减少不必要的 API 调用

---

### 2. 优化 fetchUserInfo 方法

**修改前：**
```typescript
const fetchUserInfo = async () => {
  try {
    const res: any = await getUserInfoAPI()
    if (res.code === 200 && res.data) {
      userInfo.value = res.data
      isLoggedIn.value = true
    }
  } catch (error) {
    isLoggedIn.value = false
    userInfo.value = null
    throw error
  }
}
```

**修改后：**
```typescript
const fetchUserInfo = async () => {
  try {
    const res: any = await getUserInfoAPI()
    if (res.code === 200 && res.data) {
      userInfo.value = res.data
      isLoggedIn.value = true
      localStorage.setItem('userInfo', JSON.stringify(res.data))
      return res.data
    } else {
      // 如果返回的不是成功状态，清除登录状态
      isLoggedIn.value = false
      userInfo.value = null
      localStorage.removeItem('userInfo')
      throw new Error('获取用户信息失败')
    }
  } catch (error) {
    // 清除登录状态
    isLoggedIn.value = false
    userInfo.value = null
    localStorage.removeItem('userInfo')
    throw error
  }
}
```

**改进点：**
- ✅ 明确返回用户数据
- ✅ 非成功状态也清除登录状态
- ✅ 确保状态一致性

---

### 3. 优化初始化逻辑

**修改前：**
```typescript
const initUserInfo = () => {
  const savedUserInfo = localStorage.getItem('userInfo')
  if (savedUserInfo) {
    userInfo.value = JSON.parse(savedUserInfo)
    isLoggedIn.value = true  // 直接设置为已登录
  }
}
```

**修改后：**
```typescript
const initUserInfo = () => {
  const savedUserInfo = localStorage.getItem('userInfo')
  if (savedUserInfo) {
    userInfo.value = JSON.parse(savedUserInfo)
    // 不直接设置 isLoggedIn，让路由守卫通过 fetchUserInfo 验证
  }
}
```

**改进点：**
- ✅ 不直接信任 localStorage 的数据
- ✅ 让路由守卫验证 Session 是否有效
- ✅ 避免 Session 过期但前端仍认为已登录

---

## 🎯 修复效果

### 修复前
1. 用户登录成功
2. 浏览商品页面
3. 路由守卫尝试获取用户信息
4. 如果 Session 过期，获取失败
5. 被重定向到登录页 ❌

### 修复后
1. 用户登录成功
2. 浏览商品页面（公开页面）
3. 路由守卫不验证登录状态 ✅
4. 直接显示商品页面 ✅
5. 只有访问需要登录的页面（如购物车）才验证
