

## 🔍 问题排查

### 问题1：登录后没有跳转

**检查：**
1. 浏览器控制台是否有错误
2. 用户角色是否正确
   ```sql
   SELECT username, role FROM user WHERE username = 'admin';
   ```
3. 前端缓存是否清除

### 问题2：仍然显示"登录/注册"按钮

**原因：** 前端代码被缓存

**解决：**
1. 清除Vite缓存：`rm -rf node_modules/.vite`
2. 清除浏览器缓存
3. 使用无痕模式测试

### 问题3：管理员登录后跳转到首页

**检查：**
1. 数据库中admin用户的role字段是否为'admin'
2. 前端Login.vue是否正确判断角色
3. 浏览器控制台是否有错误

### 问题4：400错误

**原因：** category接口参数问题

**已修复：** categoryId参数改为可选
