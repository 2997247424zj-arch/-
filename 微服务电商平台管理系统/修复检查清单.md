## 🔧 修复步骤

### 步骤1：清理数据库 ⚠️

- [ ] 打开MySQL客户端
- [ ] 执行以下SQL：
  ```sql
  USE e-commerce-platform;
  TRUNCATE TABLE user;
  TRUNCATE TABLE cart_item;
  TRUNCATE TABLE address;
  ```
- [ ] 确认执行成功（无错误提示）

### 步骤2：重启后端

- [ ] 在IDEA中停止当前运行的应用
- [ ] 等待3秒
- [ ] 重新运行 `ECommerceBackApplication`
- [ ] 等待启动完成（看到 "Started ECommerceBackApplication"）
- [ ] 检查控制台无错误
- [ ] 访问 http://localhost:8080/api/product/list
- [ ] 确认返回JSON数据

### 步骤3：重启前端

- [ ] 停止当前前端服务（Ctrl+C）
- [ ] 执行：`cd front/e-commerce-platform-front`
- [ ] 执行：`npm run dev`
- [ ] 等待启动完成（看到 "Local: http://localhost:5173/"）
- [ ] 访问 http://localhost:5173
- [ ] 确认页面正常加载

## 🔍 问题检查

### 如果有CORS错误

- [ ] 后端已重启
- [ ] 前端已重启
- [ ] 浏览器缓存已清除
- [ ] 使用无痕模式测试
- [ ] 检查IDEA控制台是否有错误

### 如果有密码错误

- [ ] 数据库user表已清空
- [ ] 使用新注册的账号登录
- [ ] 不使用旧的测试账号
- [ ] 检查IDEA控制台日志

### 如果无法连接后端

- [ ] 后端在8080端口运行
- [ ] 执行：`netstat -ano | findstr :8080`
- [ ] 访问：http://localhost:8080/api/product/list
- [ ] 检查防火墙设置

### 如果商品列表为空

- [ ] 检查IDEA控制台日志
- [ ] 看到"商品数据初始化完成"
- [ ] 数据库product表有数据
- [ ] 执行：`SELECT COUNT(*) FROM product;`
