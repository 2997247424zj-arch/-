# 批量导入用户使用说明

## 功能概述

管理员可以通过批量导入功能一次性添加多个用户账号，提高管理效率。系统支持CSV格式文件导入，包含数据验证和错误处理机制。

## 功能特性

- ✅ 支持CSV格式文件导入
- ✅ 自动数据验证（必填字段、唯一性检查）
- ✅ 详细的错误信息反馈
- ✅ 事务处理保证数据一致性
- ✅ 支持多种角色类型

## CSV文件格式要求

### 文件格式
- 必须是CSV格式（逗号分隔）
- 第一行为标题行
- 使用UTF-8编码保存
- 每行数据用逗号分隔，无空格

### 字段顺序（必须严格按照以下顺序）
```
姓名,用户名,身份证号,手机,角色,password
```

### 字段详细说明

| 字段名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| 姓名 | 字符串 | 是 | 用户真实姓名 | 张三 |
| 用户名 | 字符串 | 是 | 登录用户名，必须唯一 | zhangsan |
| 身份证号 | 字符串 | 否 | 18位身份证号，必须唯一 | 110101199001011234 |
| 手机 | 字符串 | 否 | 手机号 | 13800138000 |
| 角色 | 字符串 | 是 | 用户角色（见下表） | passenger |
| password | 字符串 | 是 | 登录密码 | password123 |

### 角色类型说明

| 角色值 | 角色名称 | 权限说明 |
|--------|----------|----------|
| `passenger` | 普通乘客 | 普通用户权限，可购买机票 |
| `operator` | 航空运营 | 可管理航班和订单 |
| `admin` | 系统管理员 | 拥有系统所有权限 |

## 使用步骤

### 1. 准备CSV文件
使用Excel或文本编辑器创建CSV文件，确保格式正确。

### 2. 登录管理员账号
访问管理员界面 → 人员用户管理页面。

### 3. 点击批量导入
在页面顶部找到"批量导入"按钮，点击打开导入对话框。

### 4. 上传文件
选择准备好的CSV文件，点击"开始导入"。

### 5. 查看结果
系统会显示导入结果统计，包括：
- 总行数
- 成功导入数
- 失败数量
- 详细错误信息

## 常见问题

### Q: 导入失败怎么办？
A: 查看错误信息，通常是以下原因：
- 用户名或身份证号重复
- 必填字段为空
- 角色值不正确
- 文件格式错误

### Q: 可以导入多少用户？
A: 理论上没有限制，但建议单次导入不超过1000个用户，避免超时。

### Q: 密码安全吗？
A: 建议在生产环境中修改密码策略，当前版本存储明文密码仅用于演示。

### Q: 支持其他格式吗？
A: 目前仅支持CSV格式，如需其他格式请联系开发团队。

## 技术说明

- **API端点**: `POST /api/admin/users/batch-import`
- **请求类型**: `multipart/form-data`
- **文件参数**: `file`
- **响应格式**: JSON

### API响应示例
```json
{
  "success": true,
  "message": "批量导入完成",
  "data": {
    "total": 4,
    "succeeded": 3,
    "failed": 1,
    "errors": [
      {
        "row": 2,
        "message": "用户名已存在: lisi"
      }
    ]
  }
}
```

## 注意事项

1. **备份数据**: 导入前建议备份现有用户数据
2. **测试环境**: 先在测试环境验证导入功能
3. **数据一致性**: 导入过程中如果出现错误，整个批次会回滚
4. **编码格式**: 确保CSV文件使用UTF-8编码
5. **字段顺序**: 必须严格按照指定顺序排列
6. **空值处理**: 非必填字段可以为空，但仍需保留逗号分隔符
