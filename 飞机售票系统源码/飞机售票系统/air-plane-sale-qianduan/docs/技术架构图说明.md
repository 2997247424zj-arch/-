## 2. 架构层次详解

### 2.1 前端层 (Frontend)
- **核心组件**：使用 **Vue 3.5** 框架配合 **Element Plus** UI 组件库，由 **Vue Router** 负责单页路由。
- **构建工具**：采用了 **Vite** 进行极速构建，并最终部署于 **Nginx** 服务器。

### 2.2 后端层 (Backend)
- **主框架**：基于 **Spring Boot 3.2** 构建，内嵌 **Tomcat** 应用服务器。
- **内部细节**：
    - **Spring Data JPA**：负责核心业务对象的持久化映射。
    - **Druid Pool**：高性能数据库连接池，带有实时监控。
    - **集成 SDK**：内置了 **Aliyun SMS** (短信服务) 和 **Alipay SDK** (支付宝支付) 的原生支持。

### 2.3 数据与服务层 (Data & Services)
- **数据库**：底座采用 **MySQL 8.0** 关系型数据库。
- **外部集成**：包括第三方 API 数据获取、163 邮件提醒系统以及在线客服等集成服务。

## 3. 设计特色
- **配色方案**：严格遵循模板代码中的色彩语义，前端使用绿色系，后端使用橙黄系，数据层使用红橙系。
- **逻辑流向**：清晰展示了从客户端 -> Nginx -> RESTful API -> 后端逻辑 -> 数据库/外部服务的完整闭环。
